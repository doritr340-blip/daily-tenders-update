# תבנית-אב לעיצוב קרוסלות — פורמט הוראות מדויק

מסמך זה הוא **הפורמט הקבוע** שלפיו בונים הוראות עיצוב לכל קרוסלה של הלקוחה.
כל פעם מכניסים שני קבצים — **קובץ גריד (טבלה/CSV)** ו**הגדרת פונטים** — והפלט הוא הוראות
עיצוב מדויקות, סלייד-אחר-סלייד, אחד-לאחד מול הגריד.

> אפשר להריץ את התהליך ידנית לפי המסמך הזה, או אוטומטית דרך הכלי שבתיקייה
> (`carousel/index.html`) — הכלי מזהה את העמודות מתוך הגריד עצמו ומייצר את הפלט.

---

## 1. קלט א' — קובץ הגריד (טבלה / CSV)

**כלל היסוד: כל שורה בגיליון = סלייד אחד בקרוסלה. השורה הראשונה = כותרות עמודות.**

הכלי מזהה את משמעות כל עמודה לפי שם הכותרת (עברית או אנגלית). אין חובה על סדר
או שמות מדויקים — מספיק שהכותרת מכילה אחת ממילות המפתח:

| תפקיד בעמודה | מילות מפתח שמזוהות (עברית / אנגלית) |
|---|---|
| מספר סלייד | `מספר`, `סלייד`, `#`, `slide`, `no`, `index` |
| סוג סלייד | `סוג`, `type`, `שלב`, `stage`, `kind` |
| כותרת ראשית | `כותרת`, `title`, `headline`, `כותרת ראשית` |
| כותרת משנה | `כותרת משנה`, `תת כותרת`, `subtitle`, `subheadline` |
| טקסט גוף | `טקסט`, `תוכן`, `body`, `text`, `content`, `פסקה` |
| קריאה לפעולה (CTA) | `cta`, `קריאה`, `כפתור`, `button`, `פעולה` |
| ויזואל / תמונה | `תמונה`, `ויזואל`, `רקע`, `image`, `visual`, `background`, `אייקון` |
| הערות | `הערה`, `הערות`, `notes`, `remark` |

עמודה שלא מזוהה נשמרת כ**שדה נוסף** ומוצגת בהוראות תחת "מידע נוסף" — שום נתון לא הולך לאיבוד.

### סוגי סלייד מומלצים (עמודת "סוג")
`שער` · `בעיה` · `פתרון` · `טיפ` · `רשימה` · `ציטוט` · `נתון` · `לפני/אחרי` · `סיכום` · `CTA`

לכל סוג יש ברירת-מחדל של פריסה והיררכיה (ראו סעיף 4). אם עמודת הסוג ריקה — נגזר סוג
לפי המיקום: סלייד ראשון → `שער`, אחרון → `CTA`, והשאר → `תוכן`.

## 2. קלט ב' — הגדרת פונטים

מגדירים **מערכת פונטים** אחת שתחול על כל הקרוסלה. אפשר להזין כשדות או להדביק גוש טקסט
(שורה לכל תפקיד): `תפקיד: שם-פונט | משקל | גודל`.

| תפקיד | דוגמה |
|---|---|
| כותרת ראשית (H1) | `Heebo | Bold | 64px` |
| כותרת משנה (H2) | `Heebo | Medium | 40px` |
| טקסט גוף | `Assistant | Regular | 30px` |
| CTA / כפתור | `Heebo | Bold | 34px` |
| כיתוב / הערה | `Assistant | Regular | 22px` |

אם לא הוגדר גודל — נעשה שימוש בסולם ברירת-מחדל (Type Scale) של יחס 1.25 סביב גוף 30px.

---

## 3. חוקי המרה (Grid → Design)

1. **אחד-לאחד:** כל שורה מייצרת בלוק הוראות אחד. הטקסט מועתק **מילה במילה** מהגריד — לא משכתבים תוכן.
2. **טיפוגרפיה:** כל תפקיד תוכן מקבל את הפונט+הגודל+המשקל מתוך מערכת הפונטים.
3. **RTL:** יישור בסיס לימין; מספור/חצים בכיוון עברית; אין יתומים בסוף שורה.
4. **היררכיה:** כותרת גדולה משמעותית מהגוף (יחס ≥ 1.6). ניגודיות ברורה בין רמות.
5. **בדיקת אורך:** בודקים תווים מול תקרה מומלצת לכל תפקיד ומסמנים חריגה (ראו סעיף 5).
6. **עקביות:** אותם מרווחים, שוליים (safe margins) ורשת על פני כל הסליידים.
7. **ויזואל:** אם יש עמודת ויזואל — נכתבת הנחיה לתמונה/רקע ולניגודיות טקסט מעליו.

---

## 4. פורמט הפלט — בלוק הוראות לכל סלייד

כל סלייד מקבל בלוק במבנה קבוע:

```
━━━ סלייד N — [סוג] ━━━
פריסה:        [תיאור פריסה מומלץ לפי הסוג]
כותרת ראשית:  "[טקסט מדויק מהגריד]"
              → פונט H1 · יישור לימין
כותרת משנה:   "[טקסט]"  → פונט H2
טקסט גוף:     "[טקסט]"  → פונט גוף · רוחב שורה עד ~40 תווים
CTA:          "[טקסט]"  → פונט CTA · כפתור/הדגשה
ויזואל:       [הנחיית תמונה/רקע + ניגודיות]
מרווחים:      שוליים בטוחים 8% · ריווח בין בלוקים 1.5×
בדיקת אורך:   [תקין / חריגה: X תווים מעל המומלץ]
מידע נוסף:    [עמודות שלא זוהו]
━━━━━━━━━━━━━━━━━━━━━━━
```

בסוף מופיע **סיכום קרוסלה**: מספר סליידים, מערכת הפונטים בשימוש, ואזהרות אורך מרוכזות.

## 5. תקרות אורך מומלצות (לקריאוּת במובייל)

| תפקיד | מומלץ עד | מקסימום |
|---|---|---|
| כותרת ראשית | 40 תווים | 60 |
| כותרת משנה | 60 תווים | 90 |
| טקסט גוף | 150 תווים | 220 |
| CTA | 25 תווים | 35 |

חריגה מסומנת בפלט כדי שאפשר יהיה לקצר את הטקסט בגריד לפני העיצוב.

---

## 6. איך משתמשים

1. פותחים את `carousel/index.html`.
2. מעלים / מדביקים את קובץ הגריד (CSV או הדבקה מ-Sheets).
3. מגדירים את מערכת הפונטים (או מדביקים גוש פונטים).
4. לוחצים **"צור הוראות"** — מקבלים את הבלוקים סלייד-אחר-סלייד.
5. מעתיקים / מורידים כ-Markdown ומעבירים ללקוחה או למעצב.
