# התקנת הסוכן "רדאר הבוקר" אצל כוכבית — מדריך הטמעה

> מסמך זה הוא **לצד המטמיע** (לא לכוכבית). הוא מסביר איך מתקינים את הסוכן פעם אחת,
> כך שמבחינת כוכבית זה פשוט "סוכן שמדברים איתו" — בלי לראות שום מנגנון מאחורי הקלעים.

## מה זה

`linkedin-morning-radar` הוא **Claude Skill** — יכולת מותקנת בחשבון ה-Claude של כוכבית.
אחרי ההתקנה, כל מה שכוכבית עושה זה לפנות אל Claude בשפה טבעית
("רדאר הבוקר", "מה כדאי לי להגיב היום בלינקדאין") — והסוכן נכנס לפעולה אוטומטית:
סורק את הפיד שלה ומחזיר טיוטות תגובה. היא לא מדביקה פרומפטים ולא רואה הגדרות.

## דרישה מוקדמת

- חשבון Claude בתשלום (יש לכוכבית) **עם** כלי גלישה בדפדפן פעיל — **Claude for Chrome**
  (כדי שהסוכן יוכל לסרוק את הפיד האמיתי בלינקדאין).

## התקנה (פעם אחת, ~3 דקות)

1. ארוז את התיקייה `linkedin-morning-radar/` לקובץ ZIP
   (כבר הוכן עבורך: `linkedin-morning-radar.zip` באותה תיקייה).
2. בחשבון ה-Claude של כוכבית: **Settings → Capabilities → Skills → Upload skill**
   והעלה את ה-ZIP. (במקומות מסוימים זה תחת "Create skill / Add skill".)
3. ודא שהסקיל מופעל (Enabled), וש-**Claude for Chrome** מותקן ומחובר.
4. בדיקה: פתח לינקדאין בכרום (מחובר), ואמור ל-Claude **"תריץ לי את רדאר הבוקר"**.
   הסוכן אמור לסרוק ולהחזיר רשימה עם תגובות.

זהו. מכאן זה "מובנה" — כוכבית רק מבקשת, וזה עובד.

## מה כוכבית רואה (חוויית המשתמש)

> כוכבית פותחת לינקדאין בכרום בבוקר, ניגשת ל-Claude ואומרת:
> **"בוקר טוב, מה כדאי לי להגיב היום?"**
> ומקבלת רשימה מסודרת של פוסטים + 3 תגובות מוכנות לכל אחד. היא בוחרת, מוסיפה מילה
> אישית, ומפרסמת. דקה ביום.

היא לא צריכה לדעת שום דבר על הניקוד, הקריטריונים או הפרומפטים — הכל ארוז בתוך הסוכן.

## כיוונון עתידי

- **כיוונון קול:** הוסף 2–3 תגובות אמיתיות שכוכבית כתבה לתוך
  `references/voice-and-scoring.md` (תחת "דוגמאות") — כדי שהתגובות יישמעו מדויק כמוה.
- **נושאים:** ערוך את רשימת הנושאים/הפוסלים באותו קובץ ההפניה לפי הצורך.
- אחרי עריכה — ארוז מחדש ל-ZIP והעלה גרסה מעודכנת.
