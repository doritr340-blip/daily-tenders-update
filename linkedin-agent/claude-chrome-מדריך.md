# 🤖 רדאר הבוקר עם Claude for Chrome — סורק את הפיד האמיתי שלך

זו הדרך הטובה ביותר: Claude גולש בלינקדאין **בשמך** (בחשבון שלך, בפיד האמיתי שלך),
סורק את הפוסטים, מוצא את מה ששווה להגיב עליו, ומנסח לך תגובות — **את לא מחפשת כלום.**

> 🔒 כלל זהב: Claude **רק קורא ומציע**. את זו שמאשרת, עורכת ומפרסמת. אל תאשרי לו לפרסם לבד —
> גם כדי לשמור על האותנטיות שלך וגם כדי לשמור על החשבון בטוח מול לינקדאין.

## פעם אחת — הכנה (דקה)

1. ודאי שתוסף **Claude for Chrome** מותקן ופעיל בדפדפן.
2. היכנסי ל-**LinkedIn** בכרום והישארי בעמוד הבית (הפיד) — מחוברת לחשבון שלך.

## כל בוקר — 3 צעדים פשוטים

1. פתחי את לינקדאין בכרום (עמוד הבית / הפיד).
2. פתחי את Claude for Chrome, **הדביקי את הפקודה הבאה** ושלחי:

```
את העוזרת שלי בלינקדאין. אני כוכבית ארנון — מנכ"לית KA / K-Expert AI, מומחית
להטמעת בינה מלאכותית (AI) וחוויית לקוח (CX) בארגונים. הקול שלי: "בינה מלאכותית
בגובה העיניים" — מקצועי, חם ופרקטי. אני רוצה לקדם את עצמי מול מנכ"לים, בעלי
חברות וסמנכ"לים.

עכשיו, בעמוד הזה (הפיד שלי בלינקדאין): גללי ועברי על הפוסטים מהיממה-יומיים
האחרונים. מצאי את הפוסטים ששווה לי להגיב עליהם כדי לקדם את עצמי, לפי הקריטריונים:
• כותב/ת בכיר/ה (מנכ"ל, בעל/ת חברה, סמנכ"ל) = עדיפות עליונה
• נושא רלוונטי לי: AI בארגונים, הטמעת בינה, חוויית לקוח, אוטומציה, עתיד העבודה
• יש לי פתח להוסיף ערך אמיתי (לא סתם "מסכימה")

אל תגיבי בעצמך ואל תפרסמי כלום. רק תביאי לי רשימה של עד 5 הפוסטים הכי שווים,
מסודרים מהכי מומלץ. לכל פוסט תני לי:
• שם הכותב/ת והתפקיד
• קישור לפוסט
• שורה אחת: על מה הפוסט ולמה שווה לי להגיב
• 3 טיוטות תגובה קצרות (2-4 משפטים) בקול שלי, לבחירה:
   (א) תובנה מקצועית  (ב) ניסיון מהשטח שלי בליווי ארגונים  (ג) שאלה שמושכת שיחה

כללים לתגובות: ערך אמיתי תמיד, חם ואנושי, ממצב אותי כמומחית בלי למכור שירות,
מכבד את הכותב/ת, עברית זורמת, אימוג'י אחד לכל היותר.
```

3. Claude יגלול את הפיד ויחזיר לך רשימה מוכנה.
   **בחרי פוסט → בחרי אחת מ-3 התגובות → הוסיפי מילה אישית → פרסמי בלינקדאין.** ✍️

## טיפים שמשדרגים את התוצאה 💡

- רוצה שיחפש נושא ספציפי? הוסיפי לפקודה: *"התמקדי היום בפוסטים על חוויית לקוח"*.
- רוצה שיגלול יותר עמוק? *"גללי לפחות 30 פוסטים לפני שתחליטי"*.
- תגובה לא מדויקת? בקשי ממנו: *"תכתוב גרסה יותר אישית / יותר קצרה / עם שאלה"*.
- **תמיד מוסיפים מילה משלך** לתגובה — זה מה שהופך אותה לאמיתית.
- **חוזרים אחרי שעה** לענות למי שהגיב — מכפיל את החשיפה.
