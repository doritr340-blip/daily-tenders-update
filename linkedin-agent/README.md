# רדאר הבוקר — סוכן LinkedIn לכוכבית ארנון 🌅

סוכן שכל בוקר **מחפש בלינקדאין, מסנן ומביא לכוכבית** את הפוסטים ששווה להגיב עליהם
כדי לקדם את עצמה מול מנכ"לים וארגונים — עם **טיוטות תגובה מוכנות בקול שלה**.

---

## ⚠️ קודם כל — האמת הטכנית על "שיחפש ויביא מלינקדאין"

חשוב שנדע את זה לפני שמטמיעים, כי זה קובע איך בונים:

> **ללינקדאין אין API פתוח שמאפשר לקרוא את הפיד או לחפש פוסטים אוטומטית.**
> כל כלי ש"גורף" (scraping) פוסטים מהפיד עושה זאת **בניגוד לתנאי השימוש של לינקדאין**,
> ועלול לגרום להשעיית החשבון. לכן אסור לבנות סוכן שמתחבר עם הסיסמה של כוכבית וגורף את הפיד.

**אז איך כן עושים שהסוכן "יחפש ויביא"?** יש שלוש דרכים לגיטימיות — מהקלה לאוטומטית.
בחרי אחת (אפשר להתחיל מ-1 ולשדרג ל-3):

| | דרך | אוטומציה | סיכון | עלות |
|---|---|---|---|---|
| **1** | סוכן עם חיפוש web (ChatGPT/Perplexity/Claude) | חצי-אוטומטי | ❌ אין | חינם/מנוי קיים |
| **2** | כלי העזר בדפדפן (התיקייה הזו) | ידני-מונחה | ❌ אין | חינם |
| **3** | אוטומציה no-code (Make/Zapier + ספק נתונים) | אוטומטי מלא | ⚠️ תלוי ספק | ~$30–100/חודש |

---

## דרך 1 — סוכן עם חיפוש web (הכי מומלצת להתחלה) 🥇

הרעיון: לינקדאין חוסם גריפה, אבל **פוסטים ציבוריים** של מנכ"לים ומובילי דעה
**מאונדקסים במנועי חיפוש**. סוכן AI עם גישה לאינטרנט יכול למצוא אותם ולהביא דייג'סט.

**איך מטמיעים (5 דקות):**
1. נכנסים ל-**ChatGPT** (עם דגם שמחפש באינטרנט) או **Claude** או **Perplexity**.
2. פותחים סוכן חדש / Project / Custom GPT ומדביקים את כל התוכן של `agent-prompt.md` כ-Instructions.
3. כל בוקר שולחים לו את הפקודה הזו:

```
חפש באינטרנט פוסטים ציבוריים מלינקדאין מ-48 השעות האחרונות בנושאים:
בינה מלאכותית בארגונים, הטמעת AI, חוויית לקוח (CX), אוטומציה, עתיד העבודה.
תעדף פוסטים של מנכ"לים, בעלי חברות וסמנכ"לים בישראל.
סנן לפי הקריטריונים שלך, דרג, והבא לי את רדאר הבוקר עם 5 הפוסטים הכי שווים
וטיוטות תגובה לכל אחד. צרף קישור לכל פוסט.
```

> 💡 טיפ: בונים את זה כ-**Scheduled Task / Custom GPT** ב-ChatGPT עם תזמון ל-07:00,
> וזה יגיע אלייך כל בוקר אוטומטית למייל/לאפליקציה.

**מגבלה:** מוצא בעיקר פוסטים *ציבוריים* פופולריים, לא את כל הפיד האישי שלך.

## דרך 2 — כלי העזר בדפדפן (התיקייה הזו) 🖥️

אפליקציית web פשוטה שרצה בדפדפן (כמו שאר הפרויקט), בלי שרת ובלי סיכון. שני מצבים:

- **🔦 רדאר חיפוש:** הכלי בונה עבורך **קישורי חיפוש והאשטגים ממוקדים בלינקדאין**
  (לפי קהל היעד והנושאים של כוכבית). לחיצה אחת פותחת בלינקדאין בדיוק את השיחות הרלוונטיות —
  *הסוכן מביא אותך למקום הנכון*, בלי לגעת בסיסמה ובלי לעבור על התנאים.
- **✍️ מנוע התגובות:** מדביקים פוסט שמצאת → מקבלים **ציון רלוונטיות** + **3 טיוטות תגובה**
  בקול של כוכבית + כפתור "העתק פרומפט מלא ל-LLM" לליטוש בצ'אט.

**איך מריצים:** פותחים את `index.html` בדפדפן (או מפרסמים ב-GitHub Pages וניגשים מהנייד).
מדריך מלא בתוך האפליקציה.

## דרך 3 — אוטומציה מלאה no-code (לכשתרצי "שיגיע לבד כל בוקר") 🤖

זרימה אוטומטית שמגיעה למייל/וואטסאפ ב-07:00 בלי שכוכבית תיגע בכלום:

```
[ספק נתוני LinkedIn]  →  [Make.com / Zapier]  →  [LLM עם agent-prompt.md]  →  [Email/WhatsApp]
  Phantombuster /         מסנן + מתזמן            מנקד, מדרג, כותב            דייג'סט הבוקר
  Apify / RSS.app         כל בוקר 07:00            טיוטות תגובה
```

**רכיבים:**
1. **מקור תוכן** (בחרי אחד):
   - **RSS.app / Feedly** על האשטגים ופרופילים ציבוריים — הכי "נקי" מבחינת תנאים.
   - **Phantombuster / Apify** "LinkedIn Search Export" — חזק יותר, אך ⚠️ פועל באזור אפור
     מול תנאי לינקדאין. להריץ בזהירות, בנפחים קטנים, ועל חשבון ייעודי.
2. **Make.com** (או Zapier): טריגר יומי 07:00 → אוסף את הפריטים החדשים → שולח ל-LLM.
3. **LLM** (OpenAI/Anthropic API) עם `agent-prompt.md` כ-system prompt → מחזיר דייג'סט מסונן.
4. **פלט:** מודול Email / WhatsApp / Slack ששולח לכוכבית את רדאר הבוקר.

> זו הדרך ה"שיחפש ויביא לבד" המלאה. ממליצה להגיע אליה **אחרי** שכוכבית מתרגלת את
> השגרה עם דרך 1/2, כדי שנדע בדיוק אילו נושאים וכותבים לכוונן.

📦 **ערכת הקמה מוכנה לדרך זו נמצאת בתיקייה [`automation/`](./automation/)** —
כולל מדריך צעד-אחר-צעד, `make-blueprint.json` לייבוא ישיר ל-Make.com,
והפרומפט המדויק למודול ה-LLM (`llm-system-prompt.txt`).

## 🗓️ שגרת הבוקר המומלצת (10 דקות)

1. ☕ פותחים את רדאר הבוקר (הדייג'סט / האפליקציה).
2. 👀 עוברים על 3–7 הפוסטים המדורגים.
3. ✍️ לכל פוסט שווה — בוחרים אחת מ-3 טיוטות התגובה, מוסיפים נגיעה אישית, מפרסמים.
4. 💬 חוזרים אחרי שעה לענות לתגובות-משנה (זה מכפיל חשיפה).
5. 🎯 יעד: 3–5 תגובות איכותיות ביום. עקביות > כמות.
