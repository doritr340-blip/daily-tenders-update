# 🤖 דרך 3 — אוטומציה מלאה: רדאר הבוקר נשלח לכוכבית לבד כל בוקר

המטרה: כל בוקר ב-**07:00** מגיע לכוכבית למייל דייג'סט מוכן — הפוסטים הכי שווים להגיב עליהם
היום + טיוטות תגובה בקול שלה — **בלי שהיא תיגע בכלום**.

הזרימה:

```
┌────────────┐   ┌──────────────┐   ┌─────────────────────┐   ┌──────────────┐
│ מקור תוכן   │ → │  Make.com    │ → │  LLM (Claude/GPT)   │ → │  Gmail       │
│ RSS / API  │   │ אוסף + מתזמן │   │ מנקד, מדרג, כותב     │   │ שולח 07:00   │
└────────────┘   └──────────────┘   └─────────────────────┘   └──────────────┘
```

> ⚠️ תזכורת ToS: אין API פתוח של לינקדאין לפיד. נשתמש במקור **ציבורי/לגיטימי** (RSS.app)
> כברירת מחדל. למי שרוצה כיסוי רחב יותר יש אופציית Phantombuster — אזור אפור מול תנאי
> לינקדאין, להרצה בזהירות. שתי האופציות מתועדות למטה.

## מה צריך (חד-פעמי, ~30–45 דק')

1. חשבון **Make.com** (יש Free tier — מספיק להתחלה; 1 הרצה ביום = זניח).
2. חשבון LLM אחד:
   - **Anthropic (Claude)** — מומלץ, מפתח API מ-console.anthropic.com, או
   - **OpenAI (ChatGPT)** — מפתח API מ-platform.openai.com.
3. **חשבון Gmail** של כוכבית (לשליחת הדייג'סט אליה).
4. **מקור תוכן** — אחד מהשניים:
   - **RSS.app** (מומלץ, נקי): יוצרים feed מחיפוש/האשטגים ציבוריים. ~$8/חודש.
   - **Phantombuster** "LinkedIn Search Export" (חזק, אזור אפור): ~$56/חודש.

---

## הקמה ב-3 צעדים

### צעד 1 — מקור התוכן

**אופציה A — RSS.app (מומלץ):**
1. נכנסים ל-RSS.app → New Feed → מדביקים URL של חיפוש/האשטג ציבורי בלינקדאין
   (למשל עמוד האשטג `#בינהמלאכותית` או פרופיל ציבורי של מוביל דעה).
2. יוצרים 3–5 feeds לנושאים: AI בארגונים, חוויית לקוח, עתיד העבודה וכו'.
3. מעתיקים את כתובת ה-**RSS feed** של כל אחד — נשתמש בהן ב-Make.

**אופציה B — Phantombuster:**
1. Phantom → "LinkedIn Search Export" → מזינים מילות חיפוש + מחברים session cookie.
2. מתזמנים ל-06:45, ושומרים את ה-**API endpoint** של התוצאות (JSON) ל-Make.

### צעד 2 — ייבוא ה-Blueprint ל-Make

1. ב-Make: **Create a new scenario → ⋯ (תפריט) → Import Blueprint**.
2. מעלים את הקובץ `make-blueprint.json` שבתיקייה הזו.
3. ה-scenario ייפתח עם 5 המודולים. כעת מחברים חשבונות (Make מבקש זאת על כל מודול):
   - **RSS / HTTP** → מדביקים את כתובת ה-feed מצעד 1.
   - **Anthropic/OpenAI** → מדביקים את מפתח ה-API. מוודאים ש-System Prompt = תוכן `llm-system-prompt.txt`.
   - **Gmail** → מתחברים לחשבון של כוכבית, ממלאים נמען (המייל שלה) ונושא.
4. **Schedule** (המודול הראשון) → קובעים ריצה יומית **07:00** באזור הזמן של ישראל.

### צעד 3 — בדיקה

1. לוחצים **Run once** ידנית.
2. בודקים שהגיע מייל "רדאר הבוקר" עם הפוסטים והתגובות.
3. אם הכל תקין — מפעילים את ה-toggle ל-**ON** (Scheduling). זהו, רץ לבד כל בוקר. ✅

## כוונון עדין (אחרי שבוע)

- **נושאים:** מוסיפים/מסירים feeds לפי מה שכוכבית באמת מגיבה עליו.
- **כמות:** ב-System Prompt משנים "5 פוסטים" ל-3 או 7 לפי טעם.
- **שעה:** משנים ב-Schedule.
- **ערוץ:** רוצים וואטסאפ במקום מייל? מחליפים את מודול Gmail ב-מודול WhatsApp/Telegram.
- **לוג:** אפשר להוסיף מודול Google Sheets שמתעד אילו פוסטים הוצעו — למעקב לאורך זמן.
