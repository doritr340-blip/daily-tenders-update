# אסטרטגיה — שיטת סטודיו אינטגריטי

זהו שלב 2 בתהליך הסטודיו. בדרך כלל שירן מובילה — הסקיל הזה מאפשר לכל הצוות לעבוד באותה שיטה.
קראו `dna-studio` + תיק הלקוח לפני.

## חלק א' — פגישת אסטרטגיה (אפיון מעמיק)
שאלות שעוברים עליהן עם הלקוח:
1. **מטרות עסקיות** — מה הלקוח רוצה להשיג ב-3–6 חודשים? (מכירות / לידים / מודעות / מיצוב)
2. **קהל יעד** — מי הלקוח האידאלי? מה הכאב והרצון שלו?
3. **בידול** — למה אצלו ולא אצל המתחרים? מה הסיפור הייחודי?
4. **מתחרים** — מי הם, מה הם עושים טוב, איפה הפער שלנו לנצח.
5. **נכסים קיימים** — לוגו, אתר, רשתות, תוכן ישן, רשימת תפוצה.
6. **ערוצים** — איפה הקהל נמצא? (לא חייבים להיות בכל מקום.)
7. **טון ומותג** — איך הלקוח רוצה להישמע? (להזין לתיק הלקוח.)

## חלק ב' — תוכנית תוכן חודשית
מתרגמים את האסטרטגיה לפעולה:
- **עמודי תוכן (Pillars)** — 3–4 נושאים קבועים שהמותג ידבר עליהם.
- **תמהיל פוסטים** — ערך / מאחורי הקלעים / הוכחה / מעורבות / מכירה (ראו `social-posts`).
- **לוח תוכן (Calendar)** — תאריך, ערוץ, עמוד תוכן, סוג פוסט, נושא, CTA.
- **יעדים מדידים** — מה נמדוד החודש (עוקבים / הגעה / מעורבות / לידים).

## חלק ג' — מדידה ומיטוב
- בסוף כל חודש: מה עבד, מה לא, מה משנים. (אפשר לבסס על נתוני Insights באינסטגרם.)
- מעדכנים את תיק הלקוח ואת התוכנית בהתאם.

## פלט שמגישים
מסמך אסטרטגיה + לוח תוכן חודשי. אפשר להפיק מצגת ללקוח (Gamma) או מסמך (Google Drive).
