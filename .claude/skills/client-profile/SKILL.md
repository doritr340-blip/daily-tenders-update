# תיק לקוח — סטודיו אינטגריטי

מטרת הסקיל: שכל אחד בצוות — גם מי שלא הכיר את הלקוח — ייצר תוכן/עיצוב "בקול" של הלקוח.

## איך עובדים עם זה
1. בתחילת כל משימה, פתחו את תיק הלקוח הרלוונטי בתיקייה `clients/`.
2. אם ללקוח אין עדיין תיק — צרו אחד לפי התבנית למטה (`clients/_template.md`).
3. כל תוצר חייב לעבור מול הסעיפים "טון", "מילים אסורות" ו"קהל יעד".

## חיבור לכלים
- **Canva Brand Kit / AirOps Brand Kit** — אם ללקוח יש Brand Kit, רשמו את שמו בתיק כדי שהעיצובים יהיו על-מותג.
- **Google Drive** — קישור לתיקיית חומרי הגלם של הלקוח (לוגו, תמונות, מצגות).

## תבנית תיק לקוח
```markdown
# תיק לקוח: <שם הלקוח>

## פרטים כלליים
- תחום: <ביטוח / פיננסים / קוסמטיקה / כושר / NLP-תרפיה / ...>
- איש קשר + ערוץ תקשורת:
- חבילת שירות: <6 פוסטים בחודש / ניהול מלא / קמפיינים / ...>
- סטטוס: פעיל / מושהה

## מותג
- לוגו (קישור):
- צבעי מותג (HEX):
- פונטים:
- Brand Kit (Canva/AirOps) — שם/מזהה:
- קישור לחומרי גלם (Google Drive):

## קהל יעד
- מי הלקוח האידאלי (גיל, מגדר, שלב בחיים, כאב מרכזי):
- מה הם רוצים לשמוע / מה מפעיל אותם:

## טון ומסרים
- טון הדיבור (3 מילות מפתח, למשל: "מקצועי, חם, סמכותי"):
- 3 מסרים מרכזיים של המותג:
- דוגמה לפוסט/טקסט מאושר (להעתיק סגנון ממנו):

## כללי "עשה ואל תעשה"
- מילים/ביטויים מועדפים:
- מילים/ביטויים אסורים:
- נושאים רגישים שצריך להיזהר בהם:

## ערוצים פעילים
- [ ] פייסבוק  [ ] אינסטגרם  [ ] טיקטוק  [ ] ניוזלטר  [ ] אתר
- תדירות פרסום + ימים מועדפים:
- האשטגים קבועים:

## אישורים
- האם נדרש אישור לקוח לכל פוסט? כן / לא
- מי מאשר בצד הלקוח:
```
