# מערכת הסקילים של סטודיו אינטגריטי

מערכת זו מאפשרת לכל הצוות — כותבי תוכן, מעצבות גרפיות, עורכי וידאו ושירן —
לבצע כל משימה **בדיוק בשיטה אחת**, אחידה ומקצועית, בלי תלות במי שמבצע.

כל סקיל הוא "הוראת עבודה" שכתובה פעם אחת. כשמפעילים סקיל בקלוד, הוא עובד לפי
הסטנדרט של הסטודיו. כדי להפעיל סקיל: כתבו `/<שם-הסקיל>` (לדוגמה `/social-posts`).

## הסקילים הקיימים

| סקיל | למה זה משמש | למי בעיקר |
|------|--------------|-----------|
| `dna-studio` | בסיס: ערכים, טון, סטנדרט, שלבי התהליך | כולם — נקרא בכל משימה |
| `client-profile` | תיק לקוח: כל המידע על לקוח במקום אחד | כולם |
| `intake` | קליטת בריף — פותח כל משימה חדשה | כולם |
| `strategy` | אסטרטגיה + תוכנית תוכן חודשית | שירן / אסטרטגיה |
| `social-posts` | כתיבת פוסטים לסושיאל | כתיבת תוכן |
| `copywriting` | קופי לדפי נחיתה/אתר/ניוזלטר | כתיבת תוכן |
| `graphic-design` | עיצוב פוסטים/באנרים/סטוריז | מעצבות |
| `video-editing` | עריכת רילס/טיקטוק/סרטונים | עורכי וידאו |
| `qa` | בקרת איכות לפני מסירה | כולם — בסוף כל משימה |

## איך עובד תהליך משימה מלא
1. **`intake`** — ממלאים בריף, מוודאים שיש תיק לקוח.
2. **`client-profile`** — פותחים את תיק הלקוח (טון, מותג, קהל).
3. **הסקיל לפי התפקיד** — `social-posts` / `copywriting` / `graphic-design` /
   `video-editing` / `strategy`.
4. **`qa`** — בקרת איכות לפני מסירה.
5. מסירה / פרסום (אחרי אישור לקוח אם נדרש).

## תיקיית הלקוחות (`clients/`)
- `_template.md` — תבנית ריקה ליצירת תיק לקוח חדש.
- `דוגמה-לקוח-קוסמטיקה.md` — דוגמה מלאה להמחשה (אפשר למחוק).
- לכל לקוח אמיתי: צרו קובץ `clients/<שם-הלקוח>.md`.

## איך מעדכנים
שירן (או מי שאחראי) עורך את קובץ ה-SKILL.md הרלוונטי. שינוי במקום אחד —
וכל הצוות מיושר אוטומטית. כך הסטנדרט של הסטודיו תמיד מעודכן ואחיד.

## הרחבות אפשריות בהמשך
- סקיל ניוזלטר נפרד, סקיל קמפיין ממומן, סקיל בניית אתר/דף נחיתה.
- חיבור Brand Kits ב-Canva/AirOps לכל לקוח.
- תבניות מצגת ללקוח דרך Gamma.
