# קליטת בריף (Intake)

מטרה: כל משימה מתחילה עם כל המידע הדרוש — בלי "חזרתי כי שכחתי לשאול".
זהו שלב 1 בתהליך הסטודיו (אפיון).

## מתי משתמשים
- לקוח שולח בקשה חדשה (פוסט, קמפיין, עיצוב, סרטון).
- מתחילים פרויקט חדש.

## איך עובדים
1. ודאו שיש תיק לקוח (`client-profile`). אם אין — צרו.
2. מלאו את הבריף למטה. שדה חסר = לשאול את הלקוח/שירן לפני שמתחילים.
3. שמרו את הבריף ליד התוצר כדי שכל הצוות יראה את ההקשר.

## טופס הבריף
```markdown
## בריף משימה

- לקוח:
- סוג משימה: פוסט / סדרת פוסטים / רילס / קמפיין ממומן / דף נחיתה / ניוזלטר / מיתוג / אחר
- מטרת המשימה (מה רוצים להשיג? מודעות / לידים / מכירה / אירוע):
- ערוץ/ערוצים: פייסבוק / אינסטגרם / טיקטוק / ניוזלטר / אתר
- קהל היעד הספציפי למשימה:
- מסר מרכזי / נושא:
- קריאה לפעולה (CTA):
- חומרי גלם שהתקבלו (תמונות/וידאו/טקסט/קישורים):
- מה חסר ונדרש מהלקוח:
- דדליין:
- מי אחראי בצוות:
- האם נדרש אישור לקוח לפני פרסום? כן / לא
```

## בדיקה לפני שממשיכים
- [ ] המטרה ברורה ומדידה
- [ ] יש קהל יעד ומסר
- [ ] יש את כל חומרי הגלם (או רשימת מה שחסר)
- [ ] יש דדליין ובעל משימה

רק כשכל אלה מסומנים — עוברים לשלב היצירה/העיצוב.
