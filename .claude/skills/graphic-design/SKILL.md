# עיצוב גרפי — שיטת סטודיו אינטגריטי

לפני שמתחילים: קראו `dna-studio` + תיק הלקוח (במיוחד צבעים, פונטים, לוגו, Brand Kit) + הבריף.

## כלל-על
כל עיצוב הוא **על-מותג** — צבעי המותג, הפונטים והלוגו של הלקוח, לא ברירת מחדל גנרית.
אם ללקוח יש Brand Kit ב-Canva — מתחילים ממנו.

## בריף עיצוב (למלא לפני שמעצבים)
```markdown
- לקוח + תיק:
- סוג תוצר: פוסט / סטורי / באנר / קאבר / רילס קאבר / כרטיס ביקור
- ערוץ + מידות (ראו טבלה למטה):
- טקסט שצריך להופיע (כותרת / גוף / CTA):
- חומרי גלם (תמונות/לוגו/אייקונים):
- הפניה לסגנון (דוגמה מאושרת):
```

## מידות נכונות לכל ערוץ
| תוצר | מידות (px) |
|------|-----------|
| פוסט אינסטגרם מרובע | 1080×1080 |
| פוסט אינסטגרם פורטרט | 1080×1350 |
| סטורי / רילס קאבר | 1080×1920 |
| קאבר פייסבוק | 1640×624 |
| תמונת פרופיל | 320×320 |
| באנר אתר/דף נחיתה | לפי המקום, ב-2x לרזולוציה |

## חוקי מותג בעיצוב
- צבעים: רק מפלטת המותג שבתיק הלקוח.
- פונטים: פונטי המותג בלבד. היררכיה ברורה (כותרת > גוף > הערה).
- לוגו: בגרסה הנכונה, מרווח נשימה סביבו, לא נמתח/מעוות.
- קריאוּת לפני "יפה": טקסט קריא גם במובייל קטן.
- עקביות סדרה: פוסטים של אותו לקוח נראים כמשפחה אחת.

## כלים
- **Canva** — להפקה ולשימוש ב-Brand Kit של הלקוח.
- **Figma** — לעיצובים מורכבים / דפי נחיתה / מערכת מותג.

## לפני מסירה
כל עיצוב עובר `qa` — מידות נכונות, מותג, טקסט נקי משגיאות, יישור.
